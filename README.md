# Помощник по вублинам — My Singing Monsters

Веб-приложение для острова Вублинов в игре **My Singing Monsters**. Подсказывает порядок пробуждения вублинов, быстрые рецепты по островам и цепочку бонусов «+».

## Что умеет

- **Порядок** — список 1–19 в порядке пробуждения: номер, имя (по-русски), цена статуи, окно в днях (2–14), «+ от / + кому». У Зинта бейдж «уже разбужен (3 шт)». Тап по строке раскрывает, какие яйца нужны вублину на каждом природном острове с названием острова и временем выведения.
- **Острова** — переключатель 5 островов: *Растений (и Зеркальный), Холода, Воздуха, Воды, Земли*. В каждом блоке список рецептов в порядке скорости: первая строка — главный (самый быстрый) крупно `ЯЙЦО = РОДИТЕЛЬ 1 + РОДИТЕЛЬ 2 · время`, остальные мельче. У каждого родителя чекбокс «есть на острове» (≥44 px), состояние хранится в `localStorage` и переживает перезагрузку. Если оба родителя отмечены — строка подсвечивается зелёным «можно выводить сейчас».
- **Цепочка +** — цикл из 19 связей `Имя → даёт + → Имя`. Подсказка: поставь дающего «+» рядом с получателем на острове Вублинов — выступления чаще.

Шапка всегда показывает правило: **яйца вублинов не вылупляй — zap-ом в статую; окно яиц 2–14 дней**.

## Дизайн

- Тёмная тема: фон `#16222b`, карточки `#232f3b`, акцент жёлтый `#ffe082`, текст `#e6e6f0`.
- Мобильный-first: ширина 360–430 px без горизонтального скролла, крупные тап-зоны, шрифт названий ≥20 px.
- Весь текст и имена монстров — по-русски строго из данных.
- Иконки опционально: если в `img/` лежат файлы `mon_<en>.png` (например `mon_brump.png`), они показываются рядом с именами; без иконок приложение полностью работает текстом.

## Как открыть

### Локально без сервера
1. Скачай репозиторий (Code → Download ZIP и распакуй).
2. Открой `index.html` двойным кликом в браузере — приложение работает без сервера и без ошибок в консоли.

### Через GitHub Pages
Ссылка после включения Pages: `https://<владелец>.github.io/Msmguider/` или `https://<владелец>.github.io/msm-wublin-helper/` (в зависимости от имени репозитория).

## Как включить GitHub Pages

1. На GitHub открой репозиторий → **Settings → Pages**.
2. В разделе **Build and deployment** выбери:
   - **Source:** *Deploy from a branch*
   - **Branch:** `main`, **folder:** `/ (root)`
3. Нажми **Save** — через ~1–2 минуты сайт станет доступен по адресу `https://<владелец>.github.io/<репозиторий>/`.
4. Проверь: открой ссылку, должны показаться три нижние вкладки.

> Файлы в корне: `index.html`, `style.css`, `app.js`, `data.js`, `README.md` — без сборщиков и npm, чтобы Pages работал без настроек.

## Откуда данные

Все данные лежат в `data.js` как `const MSM_DATA = {...};` и взяты **только** из блока ДАННЫЕ задания:

- `wublins` — 19 вублинов в порядке пробуждения: `n`, `en`/`ru` имена, `size` клетки, `win` окно яиц в днях, `statue` цена статуи, `plus_from`/`plus_to`.
- `islands` — 5 природных островов с `ru` названием и `blocks` по номерам вублинов; у каждого блока `w`, `ru`, `eggs` список рецептов в порядке скорости `{egg, p: [родитель1, родитель2], t: время}`.

Вики и интернет для данных не использовались. Имена в интерфейсе — только поле `ru`.
